# Flip N Match 🔮

A colorful React memory game where you match neon-tinted cards by memory.

🕹️ Features:
- Difficulty levels (Easy/Medium/Hard)
- Flip counter + personal high score tracker
- Confetti win effect 🎉
- Responsive UI with smooth 3D flip animations

🌐 Live: [https://flipnmatch.onrender.com](https://flipnmatch-y9ww.onrender.com)
